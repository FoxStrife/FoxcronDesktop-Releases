# Foxcron Desktop 1.27.8 — correção da aba Administração

- A aba Administração aparece enquanto o Desktop verifica o estado do Foxcron Agent.
- Se o Agent está habilitado e não responde, a tela avisa e mantém **Habilitar** disponível quando for seguro iniciar o módulo.
- O Foxcron Agent opcional permanece na versão 1.0.3.

Atualize pelo fluxo habitual do Foxcron. Consulte o [guia de uso](USER_GUIDE.md) e o [guia de instalação](INSTALLATION.md).
