# Foxcron Desktop 1.27.4 — Foxcron Agent 1.0.3

- O Agent seleciona a palavra-chave antes de colar a expansão, evitando que o gatilho fique no início do texto em editores assíncronos.
- O Agent dá mais tempo ao editor para ler o texto correto da macro antes de restaurar o clipboard, reduzindo trocas intermitentes de conteúdo.
- O módulo continua opcional. Se já usa o Agent, atualize o Desktop e selecione **Atualizar módulo** na administração do Agent. O fluxo preserva macros, histórico e preferências.

Atualize pelo fluxo habitual do Foxcron. Consulte o [guia de instalação](INSTALLATION.md) e o [guia do Foxcron Agent](OPTIONAL_TOOLS.md).
