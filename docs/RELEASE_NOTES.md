# Foxcron Desktop 1.27.5 — MFA manual no login AWS

- Sem cadastro de MFA automático, o Foxcron abre um pop-up protegido quando a AWS pede o código. Se também faltarem dados de login, o Foxcron solicita usuário e senha conforme as telas aparecem.
- Em **Meu acesso**, a opção **Manual** permite escolher esse fluxo. As respostas são usadas apenas na execução. O login automático continua disponível para quem já o configurou, e sessões válidas podem ser reutilizadas.
- O Foxcron Agent opcional permanece na versão 1.0.3.

Atualize pelo fluxo habitual do Foxcron. Consulte o [guia de uso](USER_GUIDE.md) e o [guia de instalação](INSTALLATION.md).
