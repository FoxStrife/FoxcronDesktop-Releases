# Foxcron Desktop 1.26.0

- Instalação por script, com downloads das dependências e atalho no Windows.
- Aviso de nova versão no menu Operador e atualização voluntária, com SHA-256 e preparação isolada.
- Repositório público de distribuição; sem necessidade de Git ou conta GitHub para instalar.
- Documentação reduzida para instalação, configuração e uso.
- Preserva AWS/Precify, login/MFA, histórico, cancelamento e relatório com alertas de contagem SQS.

Windows 10/11 x64 e internet. O script não contorna políticas corporativas nem garante aceitação por todos os controles de segurança.
